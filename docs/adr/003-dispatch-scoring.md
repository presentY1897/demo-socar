# ADR-003. 법인 배차 — 자동 배정 대신 "근거를 제시하는 추천 + 사람의 승인"

## 실제 제품과의 관계 (도메인 리서치)

쏘카의 실제 B2B 라인업을 조사해 구조를 맞췄다:

- **쏘카 비즈니스**: 임직원이 전국 공유존 차량을 직접 예약, 법인 결제·증빙 통합
- **쏘카 FMS** (2024~): **법인이 소유/장기렌트한 차량**에 앱 스마트키·예약·관제·운행일지
  자동화를 제공하는 B2B SaaS. 관리자가 임직원 권한과 배정을 관리하고, 법인 차량이
  부족하면 공유존 차량으로 대체 이용하는 옵션이 있다

이 데모의 배차 기능은 그 두 상품의 구성을 합친 **하이브리드**다:
법인 전용 차량(FMS 모델, 과금 없음)을 우선 배차하고, 부족하면 인근 공유존 차량(시간당
과금, 법인카드)으로 폴백한다. 다만 "요청 → 근거 추천 → 담당자 승인" 워크플로 자체는
실제 쏘카 기능의 복제가 아니라, 반납·이동 시간이 일정에 미치는 영향을 담당자가 판단할
수 있게 하자는 이 프로젝트의 제안 설계다.

## 상황

법인 오피스의 차량 배차는 개인 예약과 결이 다르다:

- 차량이 반납되고, 그 차를 다음 사람이 쓰러 **걸어가는 시간**이 실제 일정에 영향을 준다
- 앞 이용자가 늦게 반납하면 뒤 일정이 연쇄로 밀린다
- 배차 담당자는 기계가 모르는 맥락(임원 일정, 우천, 짐의 양)을 알고 있다

완전 자동 배정은 이 맥락을 무시하고, 완전 수동 배정은 담당자가 매번 지도를 보며 계산해야 한다.

## 결정

**시스템이 계산하고, 사람이 결정한다.** 요청이 들어오면 후보 차량을 점수화해 상위 3개를
근거 문장과 함께 제시하고, 담당자가 선택·승인한다.

### 스코어링

```
score = 100 × (0.4 × 이동시간 + 0.25 × 반납버퍼 + 0.15 × 지연리스크 + 0.2 × 전용차량)
```

| 요소 | 계산 | 이유 |
|---|---|---|
| 이동시간 | 오피스→존 도보 시간을 A*로 추정, 30분을 0점으로 선형 | 사람이 체감하는 가장 큰 비용 |
| 반납버퍼 | 직전 예약 반납 예정과 희망 시작 사이 여유(분), 120분 이상 만점 | 지연 반납의 파급을 흡수하는 완충 |
| 지연리스크 | 해당 차량의 최근 30일 지연 반납률 (표본 3건 미만은 전체 평균) | 데이터가 있는데 안 쓰는 건 손해 |
| 전용차량 | 법인 전용 차량(FMS)이면 만점, 공유존 차량이면 0 | 전용 차량은 추가 과금이 없다 — 비용이 근거로 드러나야 담당자가 판단한다 |

점수는 정렬 기준일 뿐이고, 화면에는 반드시 근거가 함께 나간다:

> 1. 아이오닉 5 [전용] — 92.1점
>    · 법인 전용 차량 — 이용 과금 없음, 운행일지 자동 기록
>    · 데모컴퍼니 사옥 주차장까지 도보 약 1분 (60m)
>    · 직전 반납 예정 후 45분 여유
>    · 최근 30일 지연 반납률 8%

가중치(0.4/0.25/0.15/0.2)는 "이동시간 > 버퍼·비용 > 리스크"라는 순서만 담은 초기값이다.
실서비스라면 담당자의 선택 로그(추천 1위가 아닌 후보를 고른 비율)를 지표로 삼아 보정한다.

### 이동시간 추정 — 교체 가능한 인터페이스

```ts
interface TravelTimeEstimator {
  estimateWalk(from: Coord, to: Coord, region: string): Promise<TravelEstimate>;
}
```

- 기본 구현: OSM 보행 도로망 + **A\* 최단경로** × 도보 4.5km/h ([ADR-004](004-road-graph-pipeline.md))
- 그래프가 없는 지역은 직선거리 × 우회계수 1.3 폴백 — 추정 방식이 근거 문장에 명시된다
- Kakao Mobility 같은 실제 길찾기 API로 바꿀 때는 이 인터페이스의 구현체만 교체한다

### 승인 = 예약 생성

승인 시 일반 예약과 **같은 코드 경로**(동시성 제어, 결제 멱등성)를 통과한다.
추천 이후 다른 예약이 차량을 선점했다면 409와 함께 후보를 재계산해 담당자가 다시 고르게 한다.
배차용 우회 경로를 만들지 않아 정합성 규칙이 한 곳에 남는다.
