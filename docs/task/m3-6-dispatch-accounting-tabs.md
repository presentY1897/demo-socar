# M3-6 — 작업/배차 + 회계 탭 UI

- 마일스톤: M3 (운영 백오피스 재설계) · 규모 M
- 상태: ☐ 대기
- 의존: M3-3 (배차는 M2-4 API 사용)

## 목적

핸들러 배정을 화면으로 올리고(피드백 #5 "운송기사 배차"), 매출·손익을 회계 탭으로 격리한다(피드백 #4).

## 작업 내용

- [ ] **작업/배차 탭**:
  - 미배정 작업 큐: 타입·차량·출발→도착·기한 — 배정 버튼 → 핸들러 선택 모달(거리순 추천, M2-4)
  - 진행 중 작업 보드(배정/이동 중), 핸들러별 오늘 처리량
  - REPOSITION 수동 생성 폼 (차량·출발/도착 존·기한)
- [ ] **회계 탭**:
  - 월 손익 요약: 매출 − 비용(리스료+보험료+주차장 계약비) 카드
  - 기존 매출/예약/가동률 지표와 일별 차트를 이 탭으로 이동 (운영 홈에서 제거)
  - 차트는 일단 기존 라이브러리 그대로 옮기고, Chart.js 교체는 M4-1에서 일괄

## 산출물

- 작업/배차 탭 · 회계 탭 컴포넌트 · 기존 매출 화면 이동/정리

## 완료 기준

- 백오피스에서 미배정 작업 배정 → 핸들러 계정 큐에 반영(교차 확인) · 회계 탭에서 손익 합계가 API 값과 일치 · 운영 홈에 매출 지표가 더 이상 없음

## 테스트

- **백엔드**: 해당 없음 (M3-3·M2-4에서 완료)
- **프론트(MSW)**: 작업/배차 — 미배정 큐 렌더 · 배정 모달(추천 순서 표시)에서 배정 요청 페이로드 검증 · REPOSITION 생성 폼 / 회계 — 손익 카드가 MSW 값과 일치 렌더
