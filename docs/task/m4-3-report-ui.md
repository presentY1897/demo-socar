### 결정

- **URL이 시작 상태이자 공유 수단**이다. 화면은 URL에서 한 번 읽어 상태로 들고, 조작할 때마다 `router.replace`로 되쓴다. 매 렌더 URL에서 파생하지 않는 이유는 탭 셸이 이미 같은 방식(딥링크로 시작 → 이후 화면 상태)을 쓰기 때문이다
- **남이 준 링크가 화면을 깨뜨리지 않는다**: 알 수 없는 지표·축은 조용히 기본값으로 흡수하고, 허용되지 않는 조합은 그 지표가 쓸 수 있는 첫 축으로 옮긴다 (400을 받는 조합이 화면에 남지 않게)
- 지표를 바꾸면 **선택지 자체가 바뀐다** — `reportGroupBysFor()`가 단일 소스라 화면이 다시 판단하지 않는다
- 비율 지표의 전체 값 카드에 "행 평균이 아닌 가중 평균"을, 존 점유율에 "기간과 무관한 현재 값"을 적어 둔다
