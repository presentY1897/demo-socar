# M4-3 — 리포트 UI

- 마일스톤: M4 (지표·차트·Export) · 규모 S
- 상태: ☐ 대기
- 의존: M4-1, M4-2

## 목적

피드백 #6 "백단에서 Chart.js를 통해서 바로 보여주는 기능" — 운영자가 필터를 조작하면 즉시 차트와 표가 갱신되는 리포트 화면.

## 작업 내용

- [ ] 백오피스에 리포트 화면 추가 (회계 탭 하위 또는 별도 "리포트" 탭 — 구현 시 판단):
  - 필터 폼: 지표 선택 · 기간(프리셋: 최근 7일/30일/이번 달 + 직접 입력) · groupBy · 존/차종 필터
  - 결과: Chart.js 차트(M4-1 래퍼, groupBy=day는 라인, zone/model은 바) + 동일 데이터 표
  - 필터 변경 시 즉시 재조회(SWR), URL 쿼리에 필터 상태 보존(공유 가능)
- [ ] Export 버튼 자리 마련 (동작은 M4-4)

## 산출물

## 완료 기준

- 필터 변경 시 차트/표 동기 갱신 · URL 복사로 같은 리포트 재현 · 지표 5종 모두 렌더
