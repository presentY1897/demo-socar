## 로컬 런타임 스모크 결과 (2026-09-01, 배포 대체)

`node dist/main.js` :4000 + `socar_m4`(시드 v9), `ops@demo.mocar.kr` 토큰.

**리포트 API** — 허용 12조합 전부 200:

| 지표 | day | zone | model |
|---|---|---|---|
| 매출 | 6,781,100원 / 30행 | 30행 | 8행 |
| 가동률 | 1.4% / 30행 | 31행 | 9행 |
| 존 점유율 | — | 8.7% / 31행 | — |
| 작업 처리량 | 12건 / 30행 | 12행 | — |
| 지연 반납률 | 10.2% / 30행 | 31행 | 9행 |

허용되지 않는 조합(`zoneOccupancy/day`·`zoneOccupancy/model`·`taskThroughput/model`)과
잘못된 지표·축·기간(366일 초과·형식 오류)은 전부 400. `/ops/reports/options` = 존 31 · 차종 9.

**Export 5종** — BOM `EF BB BF` · 개행 전부 CRLF · `csv` 모듈 재파싱 시 열 폭 단일:

| 대상 | 행 | 열 | ASCII 대체본 / 실제 이름 |
|---|---|---|---|
| 리포트 | 31 | 2 | `report-revenue-by-zone_2026-08-03_2026-09-01.csv` / `리포트_매출_존별_…` |
| 차량 표 | 74 | 20 | `fleet_2026-09-01.csv` / `차량목록_2026-09-01.csv` |
| 작업 목록 | 17 | 14 | `handler-tasks_2026-09-01.csv` / `작업목록_…` |
| 유의 유저 | 3 | 7 | `at-risk-users_2026-09-01.csv` / `유의유저_…` |
| 내 예약 | 51 | 18 | `my-reservations_2026-09-01.csv` / `내예약_…` |

**이스케이프 왕복(런타임)**: 존 이름을 `테스트존, "인용" 포함\n둘째 줄`로 바꿔 export →
원시 CSV가 `"테스트존, ""인용"" 포함\n둘째 줄",6.7\r\n` 이고 재파싱 값이 원본과 **정확히 일치**,
열 폭도 유지됨. 확인 후 원래 이름으로 복구.

**권한**: 개인 계정으로 `/ops/reports`·`/ops/reports/options`·Export 4종 전부 **403**,
무토큰 **401**. `?format=xlsx` 400, `?format=` 없으면 기존 JSON 그대로(Content-Disposition 없음).

**데모 계정 7종** 로그인 → 역할·등급·랜딩·대표 API 전부 200 (user/viewer/member/approver/admin/ops/handler).

**엑셀 수동 확인은 하지 않았다** — 환경에 엑셀이 없다. BOM 바이트·CRLF·RFC 4180 왕복·한국어
헤더를 위 자동 검증과 단위 테스트 19건으로 대체했다.

## 스모크가 잡은 것 (M4-5에서 수정)

1. **`작업 처리량` 지표가 항상 0** — 시드에 완료된 핸들러 작업이 없어 리포트와 작업/배차 탭의
   처리량 차트가 빈 채로만 보였다. 지난 2주에 흩어진 완료 작업 12건을 시드에 추가(`SEED_VERSION` 9).
   기능이 있어도 데모에서 확인할 수 없으면 없는 것과 같다.
2. **ASCII 대체 파일명이 `__________2026-09-01.csv`** — 한글이 전부 밑줄이 되어 읽을 수 없었다.
   `ExportSpec.asciiName`을 두어 대상별 영문 이름(`fleet`·`handler-tasks`·`at-risk-users`·
   `my-reservations`·`report-{지표}-by-{축}`)을 싣고, 연속 밑줄은 접는다.
