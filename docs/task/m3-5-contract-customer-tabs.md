# M3-5 — 존/계약 + 고객 탭 UI

- 마일스톤: M3 (운영 백오피스 재설계) · 규모 M
- 상태: ☑ 완료
- 의존: M3-3

## 목적

피드백 #5 "주차장 계약·잔여 자리, 유의할 유저 정보" + M1-7 문의의 답변 창구.

## 작업 내용

- [x] **존/계약 탭**:
  - 존 목록: 이름·주소(실데이터) · 유/무료 배지 · 계약 파트너 · 월 비용 · 계약 기간(만료 임박 강조) · 면수 대비 현재 배정/잔여 자리 (잔여 0 경고)
  - 행 확장 → 계약 수정 폼(`PATCH /ops/zones/:id/contract`)
- [x] **고객 탭**:
  - 유의 유저 목록(`GET /ops/users/risk`): 지연 반납 N회 · 사고 접수 · 결제 거절 배지, 유저 클릭 → 최근 예약/사고 이력
  - 문의함: OPEN 문의 목록 → 답변 작성(`POST /ops/inquiries/:id/answer`) → ANSWERED 전환

## 산출물

- 존/계약 탭 · 고객 탭 컴포넌트

## 완료 기준

- 계약 수정이 목록에 반영 · 문의 답변이 이용자 `GET /me/inquiries`에 표시(교차 확인) · 시드 유의 유저 1명 이상 노출

## 완료 기준 검증 메모

- 유의 유저 시드: M3-1 시드에 이미 들어 있다 (M3-3 통합 테스트 "유의 유저: 집계값이 실제 이력과 맞고 임계치를 넘은 유저만 나온다"가 시드 데이터로 통과). 추가 시드 불필요
- 문의 답변 → 이용자 `GET /me/inquiries` 반영은 M3-3 통합 테스트("문의 답변: OPEN → ANSWERED, 이용자 문의함에도 그대로 보인다")가 교차 확인한다 — 화면은 같은 엔드포인트를 쓴다

### 설계 메모

- **판정은 전부 서버 값을 그대로 쓴다**: 계약 만료 임박(`contract.expiringSoon`·`dDay`), 잔여 자리(`freeSlots`), 리스크 임계치(`USER_RISK_THRESHOLDS`). 화면이 다시 계산하면 경고 피드와 목록이 서로 다른 말을 한다
- **초과 배정(잔여 음수)을 0으로 깎지 않는다** — 화면에서 숨기면 그 존으로 차를 계속 보내게 된다 (M3-3 서비스와 같은 판단)
- **무료로 바꾸면 월 비용을 0으로 되돌린다** — 남은 금액이 회계 탭의 주차장 계약비에 그대로 실리면 손익이 조용히 틀어진다. 조합 검증(유료 ↔ 월 비용, 시작 ↔ 종료)은 서버와 같은 zod 스키마로 미리 돌린다
- **리스크 점수(riskScore)는 화면에 띄우지 않는다** — 순위를 만드는 값일 뿐 사람이 못 읽는다. 배지는 "무엇이 몇 번"만 보여주고 임계치를 넘은 것만 빨갛게 칠한다(`lib/ops-users.ts`)
- **답변 완료 문의에는 입력창을 두지 않는다** — 서버가 재답변을 409로 막는 이유(이용자가 본 문구와 갈리는 것)를 화면에서도 같은 방식으로 지킨다
