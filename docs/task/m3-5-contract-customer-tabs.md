# M3-5 — 존/계약 + 고객 탭 UI

- 마일스톤: M3 (운영 백오피스 재설계) · 규모 M
- 상태: ☐ 대기
- 의존: M3-3

## 목적

피드백 #5 "주차장 계약·잔여 자리, 유의할 유저 정보" + M1-7 문의의 답변 창구.

## 작업 내용

- [ ] **존/계약 탭**:
  - 존 목록: 이름·주소(실데이터) · 유/무료 배지 · 계약 파트너 · 월 비용 · 계약 기간(만료 임박 강조) · 면수 대비 현재 배정/잔여 자리 (잔여 0 경고)
  - 행 확장 → 계약 수정 폼(`PATCH /ops/zones/:id/contract`)
- [ ] **고객 탭**:
  - 유의 유저 목록(`GET /ops/users/risk`): 지연 반납 N회 · 사고 접수 · 결제 거절 배지, 유저 클릭 → 최근 예약/사고 이력
  - 문의함: OPEN 문의 목록 → 답변 작성(`POST /ops/inquiries/:id/answer`) → ANSWERED 전환

## 산출물

- 존/계약 탭 · 고객 탭 컴포넌트

## 완료 기준

- 계약 수정이 목록에 반영 · 문의 답변이 이용자 `GET /me/inquiries`에 표시(교차 확인) · 시드 유의 유저 1명 이상 노출

## 완료 기준 검증 메모

- 유의 유저 시드: 지연 반납 이력이 있는 데모 데이터가 이미 있는지 확인, 없으면 M3-1 시드에 추가

## 테스트

- **백엔드**: 해당 없음 (M3-3에서 완료)
- **프론트(MSW)**: 존/계약 — 목록 렌더(만료 임박·잔여 0 강조) · 계약 수정 폼 제출/반영 / 고객 — 유의 유저 배지 렌더 · 문의 답변 작성 → 상태 ANSWERED 갱신
