# M3-4 — 운영 홈 + Fleet 탭 UI

- 마일스톤: M3 (운영 백오피스 재설계) · 규모 L
- 상태: ☐ 대기
- 의존: M3-3

## 목적

피드백 #3·#4·#5의 화면 반영 핵심. `/dashboard`를 매출 화면에서 **운영 센터** 탭 구조로 개편하고, 그중 운영 홈과 Fleet 탭을 만든다.

## 작업 내용

- [ ] `/dashboard` 탭 셸 개편: ① 운영 홈 ② 차량 ③ 작업/배차 ④ 존/계약 ⑤ 고객 ⑥ 회계 (③~⑥은 M3-5·6에서 채움)
- [ ] **운영 홈 탭**:
  - 상단 스탯: 지금 운행 중 대수 · 탁송 진행 중 · 오늘 예약 수 · 미배정 작업 수
  - 경고 피드(`GET /ops/alerts`): 연료 부족/보험 만기/계약 만료/지연 반납 — 항목 클릭 시 해당 탭으로 이동
  - 실시간 차량 지도: SSE 텔레메트리로 위치·상태 갱신 (ZoneMap 확장)
- [ ] **차량(Fleet) 탭**:
  - 전 차량 표: 상태 배지 · 배정 존 · 연료(게이지) · 주행거리 · 다음 예약 · 보험 D-day, 정렬/상태 필터
  - 행 클릭 → 상세 패널: 센서 값 실시간 · 스마트키 조작 이력 · 도입 비용/보험 · 정비 메모 입력
  - 신규 차량 등록 폼(`POST /ops/vehicles`): 차종·연료·요금제·배정 존·도입 방식/금액·보험

## 산출물

- dashboard 페이지 개편(탭 셸 + 홈/Fleet) · 경고 피드/차량 표/상세 패널/등록 폼 컴포넌트

## 완료 기준

- `ops@demo.mocar.kr`로 경고 3종 이상 확인(시드 케이스), 운행 중 차량이 지도에서 움직임, 차량 등록 → 표에 즉시 반영
